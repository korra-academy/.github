# Korra Academy

**Live online tutoring and hands-on tech education, from the UK.**

Korra Academy is an online learning campus at **[korra.academy](https://korra.academy/)**. We combine live 1-to-1 tutoring, small group sessions and a self-paced library covering coding, AI skills, cyber security, exam preparation and professional certifications.

## What is Korra Academy?

Korra Academy is an independent online academy. Learning happens live with human tutors — one-to-one sessions and small groups — backed by a structured curriculum library organised around the same eight doors. Membership and session pricing is published at [korra.studio/pricing](https://korra.studio/pricing).

## Open source

We publish free learning resources and small, dependency-free teaching apps — one for each door:

- [coding-for-kids-activities](https://github.com/korra-academy/coding-for-kids-activities) — screen-free coding activities + a first game kids can edit
- [gcse-revision-timetable](https://github.com/korra-academy/gcse-revision-timetable) — printable revision timetable generator, one HTML file
- [career-change-to-tech-roadmap](https://github.com/korra-academy/career-change-to-tech-roadmap) — a realistic 6-month plan for switching into tech
- [ai-for-small-business-guide](https://github.com/korra-academy/ai-for-small-business-guide) — plain-English guide to using AI in a small business
- [tutoring-lesson-plan-templates](https://github.com/korra-academy/tutoring-lesson-plan-templates) — session plans, assessments and progress reports for tutors
- [it-certification-roadmap](https://github.com/korra-academy/it-certification-roadmap) — which IT certification to take, in what order
- [build-your-first-chatbot](https://github.com/korra-academy/build-your-first-chatbot) — a chatbot in one HTML file, no installs, no API keys
- [vibe-coding-starter-prompts](https://github.com/korra-academy/vibe-coding-starter-prompts) — copy-paste prompts for building your first apps with AI

Everything is MIT licensed. Use it in your classroom, your business or your bedroom.
